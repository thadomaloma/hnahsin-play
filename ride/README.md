# Aizawl Ride routes

`routes.json` (two featured routes, from `source/ride/bake.py`) and `city.json` (the Aizawl map: 18 veng and delivery jobs between them, from `source/ride/bake_city.py`) hold real Aizawl roads for the Aizawl Ride game, made by
`source/ride/bake.py` from map data prepared in the Zoram Delivery project.
